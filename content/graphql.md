## Module Overview
This module teaches GraphQL across the stack, pairing a Spring Boot backend with a React client. You’ll learn schema design, queries, and mutations, then apply resolvers and client-side data workflows to build flexible APIs and UIs. These skills support ESI teams by reducing over-fetching, improving API consistency, and speeding up iteration during implementation and code review.

## Learning Objectives
- Explain GraphQL schemas, queries, mutations, and resolver responsibilities.
- Build a Spring Boot GraphQL API backed by Spring Data JPA and MySQL.
- Apply GraphQL client patterns in React for fetching, caching, and updates.
- Troubleshoot common GraphQL integration issues across server and client layers.
- Evaluate when GraphQL fits better than REST for evolving product requirements.
