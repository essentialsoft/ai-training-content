## Module Overview
This module builds Python skills through daily, project-based practice. You will learn core Python, debugging, and clean coding habits, then apply them to automation, web apps, APIs, and data workflows. The focus on shipping small projects aligns with ESI’s development cycle by strengthening implementation speed, test-ready code, and iterative delivery across engineering roles.

## Learning Objectives
- Identify core Python syntax, control flow, and data structures through daily practice.
- Apply debugging and refactoring techniques to improve code clarity and reliability.
- Build automation scripts and web scrapers using common Python libraries.
- Create web applications and APIs using a lightweight Python framework.
- Evaluate simple data analysis and visualization workflows to extract insights.
