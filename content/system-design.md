## Module Overview
This module strengthens core software design and system architecture skills used to build scalable, maintainable systems. You’ll start with SOLID principles for clean, flexible code, then learn how architects define requirements, APIs, and high-level components for large-scale systems. You’ll also practice modern system design patterns and interview-style case studies that mirror real ESI design reviews and technical planning.

## Learning Objectives
- Explain SOLID principles and recognize common design smells in object-oriented code.
- Apply architecture frameworks to translate ambiguous requirements into system components and APIs.
- Build scalable system designs using caching, load balancing, sharding, and microservices trade-offs.
- Evaluate architectural options for scalability, availability, reliability, and security under constraints.
- Troubleshoot design decisions by identifying bottlenecks and improving robustness with patterns.
