## Module Overview
This module introduces end-to-end web development, from building responsive front-end UIs to creating back-end APIs and working with databases. You’ll practice core web technologies and modern frameworks, then connect the pieces into real applications. The skills map directly to ESI roles that ship AI-assisted features—scoping requirements, building interfaces, integrating services, and iterating quickly with AI-powered coding and testing workflows.

## Learning Objectives
- Identify the core components of full-stack web applications and how they interact.
- Build responsive front-end pages using HTML, CSS, and modern JavaScript.
- Apply React to create reusable UI components and manage client-side state.
- Create back-end services with Node.js and connect them to databases.
- Evaluate basic deployment and version control practices for team-based delivery.
